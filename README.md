# 550HW2
MATLAB code to solve the Poisson equation using an immersed boundary.
## Contents
- `550_HW2.pdf` - Compiled Homework PDF
- `HW2.tex` - LaTeX file
- `figures/` - jpegs of figures used in Homework report
- `MATLAB code/` - code used to create figures

## Usage
#### View Homework
- Open `550HW2.pdf` to read the homework.

To compile the homework from its LaTeX source, run:
```bash
latexmk HW2.tex
```
